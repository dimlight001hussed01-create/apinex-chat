# APInex Claude Chat — Claude-style UI

Mobile-first Claude-inspired interface with APInex backend, image/file uploads, chat history, new chat, model settings, and Render deployment support.

## Render
- Build Command: `npm install`
- Start Command: `npm start`
- Environment Variable: `APINEX_API_KEY` = NEW APInex key
- Optional: `APINEX_BASE_URL` = `https://api.apinex.bond/v1`

Do not put the API key in the frontend or GitHub. Enter the exact Claude model ID from APInex in Settings.
